# APIsRouter

APIsRouter supplies paid social, search and web data for your agent's tasks.
This plugin contains a remote MCP connector and one shared usage Skill.

Install the plugin through your host's plugin interface. In Claude desktop or
Cowork, open the plugin's Connectors tab and add/connect APIsRouter. In Codex
desktop, open the installed plugin and connect when prompted. Sign in to
APIsRouter, choose the allowed operations, spending limit and expiry, then
start a new chat or task.

Try: “Find the operation for a TikTok account's region and quote one request.”
The agent checks the catalog contract and price before purchasing within your
approved limit. Your account shows the result's order and charge. Keep the
request reference when a request pauses; continuing it avoids a duplicate
purchase.

Connection URL: `https://api.apisrouter.com/mcp`.
